# Library Automation System

This is a Java-based library automation project developed using **Object-Oriented Programming (OOP)** principles and **Swing GUI**.

## Features
- Book and EBook management
- Borrowing and returning books
- Searching by title
- Filtering by category
- Dynamic GUI with theme options
- Input validations and error handling

## Technologies
- Java 17+
- Swing GUI

## How to Run
1. Compile all Java files in `LibraryAutomationSystem/` package
2. Run `LibraryAutomation.java`

```bash
javac LibraryAutomationSystem/*.java
java LibraryAutomationSystem.LibraryAutomation
